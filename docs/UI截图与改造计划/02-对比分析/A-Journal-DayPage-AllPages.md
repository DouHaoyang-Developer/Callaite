2. **Tab 条改造**：36vp → 40vp，页签宽度自适应，只有当前 Tab 高亮。（J4+J5）
3. **正文阅读宽度**：960vp 固定宽 → 最大 760vp 居中。（J6）
4. **日期块压缩**：108vp 节距 → 紧凑块，占位符与标题间距 73.5vp → 12–16vp。（J7）
5. **空态去重**：重复 7 次的「输入内容，按 / 查看命令」收敛为一次。（J8）

### 跨页共性问题（改一处受益三页）

1. **外壳比例**：Ribbon 46vp + 活动栏 44vp + 面板 216vp（合计 306vp）；Obsidian = 单 Ribbon 44px + 侧栏 240–260px。**方案三落地后三页同时受益**。

### 证据来源与不确定项

- 面板 216vp、活动栏 44vp、Ribbon 46vp、Tab 条 36vp、状态栏 26vp、正文宽 960vp、Journal 节距 108vp、AllPages 行距 48vp、日期列 x=1327.5 —— 均直接取自 3 份 `*_dump.json` 的 bounds（px ÷ 2）。
- **字号**（如标题"约 28–30vp"、列表文字"约 16–18vp"）：dump 不含字号字段，为截图目测估算，标注为估算值。
- **配色色值**：dump 中文字节点的 `backgroundColor` 多为 `#00000000`（透明，颜色来自父级或字体色），因此正文/标题的**实际前景色为截图目测**，非 dump 精确值。仅容器底色（`#FFF2F3F5`、`#FFDDDDDD`）为 dump 实测。
- **不确定**：Tab 条高度按内容区起点 y=79 与主区起点 y=43 之差推算为 36vp（dump 中该 Row 节点自身 bounds 为 (310,43) 1130×36，两者一致，可信度较高）；AllPages 日期列"蓝色"为截图目测，dump 未能给出前景色佐证。
