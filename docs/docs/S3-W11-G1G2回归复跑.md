### 2.4 「多块批量删除的 undo 栈行为」——**已知行为是否仍然如此**

**分两部分回答**（任务要求「请核实这个已知行为是否仍然如此」✓）：

#### ① `N 次 delete-block ⇒ N 个 undo 条目`（陷阱 16 的原文）——**仍然成立 ✓** Ⓐ

## 4. 任务 3（顺带）· E12 的第二个边界：Esc 键码
