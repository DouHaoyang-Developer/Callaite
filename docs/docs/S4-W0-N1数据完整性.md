## 10. 方法论留存（值得复用的三条）

1. **🔴 「探针位置」决定「结论真伪」** ✗✓ —— 同一个「让写盘失败」的意图，
   注入在**漏斗之外**得到 `flushed 0/1`（失败被上报），注入在**`catch` 之内**得到 `flushed 1/1`（失败被吞）。
   ⇒ **探针必须复刻「真实故障的归宿」，而不是只复刻「一个异常」** ✓✓
   （这是陷阱 9 / 42 的同族：**仪器本身必须先被验证**）
2. **两条 UI 枚举通道的 id 空间不相通** ✗✓ —— `dumpLayout` 的 `id=` 与 `-uiLayout` 的 `id:`
   **交集 = 0** ⇒ 混用必然点错 ✓；且**每轮枚举都会重排**（本轮因读-点间隙点错过 `W` 行与 `2026-10-02` 行 ✗）
   ⇒ 正解是「**同一进程内 dump → 判定 → 点击**」✓（本窗口 `dev.py` 即此实现 ✓）
3. **`hdc shell cat` 会把 LF 转成 CRLF** ✗ —— 会让「字节数/md5」判据**系统性偏大**
   （`PAGEA.md` 实际 30 B，经 `shell cat` 得 34 B）✓
   ⇒ **字节级判据一律用 `ls -l`（权威）+ `hdc file recv` 后本地算 md5** ✓✓
   （本窗口 `vsnap.py` 即此实现 ✓）
