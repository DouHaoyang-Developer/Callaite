### 2.2 Ⓑ 根因（代码级，逐行可核）

`entry/src/main/ets/utils/MarkdownSegmenter.ets:222-239`：

```ts
// Wiki 链接 [[target]] 或 [[target|display]]
if (text.startsWith('[[')) {            // ← ✗ 没有 position 实参 ⇒ 只看「串首」，与游标 i 无关
  const closeIdx = text.indexOf(']]', 2);  // ← 也恒从 2 起，与 i 无关
  if (closeIdx !== -1) {
    result.push({ text: '[[', type: 'syntax' });
    const inner = text.slice(2, closeIdx);
    if (inner) { result.push(...parseInlineMarkdown(inner)); }
    result.push({ text: ']]', type: 'syntax' });
    i = closeIdx + 2;                   // ← ✗ 当 i 已越过 closeIdx 时，i 不前进
    continue;
  }
  …
}
```

**当 `text` 以 `[[` 开头、且首个 `]]` 之后还有字符时**：`i` 被写成 `closeIdx + 2`（一个**已经走过**的位置）⇒
下一轮循环 `text.startsWith('[[')` **仍为 true**（它看的是串首，不是 `i`）⇒ 再走一次同一分支 ⇒ **`i` 永不前进**，
每轮 push 3 个 segment ⇒ `result` 无界增长 ⇒ `Heap::AllocateHugeObject` 79 MB 失败 ⇒ OOM ⇒ 应用被杀。
（同函数 `:285-292` 的注释里已经记录过**同族第 1 例**「孤立 `!` 死循环」，由 `d4d1b5f` 修掉 ⇒ **这是同族第 2 例** ✗）
