## 三、裁决：**不回切 WebView**，把预算转投 **A-2**
**理由**：
1. **B 形态已落地并可用** ✓（W2 实测：打字过程中即落盘 ✓；三条硬要求全部落地 ✓；四条零破坏复核通过 ✓）⇒ 此刻回切会**丢弃已完成的工作** ✗

3. **A-2 是正交且小范围的** ✓（设计文档 §① A-2：**消除无界单次停顿** ✓ —— 含「上界 + 让出」✓）；**A-0/A-1 都不修它** ✗ ⇒ 它才是对症的方向 ✓
