## 四、两个口径（写文档 / 做验收时请遵循）

1. **证据分级**：**Ⓐ** 真实设备操作（点击/按键 + 截图或磁盘字节）· **Ⓑ** 代码级论证 · **Ⓒ** 受控探针。
   **不得把「无法验证」写成「通过」** —— 写「代码就绪、待验收」，并登记进 `docs/待验收清单.md`。
2. **硬判据优先**：能看**磁盘字节 / MD5** 的就不要只看 UI（本项目的删除类、撤销类缺陷都曾被 UI 掩盖）；
   **改动前后逐字节回基线**是最强验收形式。
